Validate an X.509 trust chain

Supply a Root CA, any number of Intermediate CAs, and the server certificate. Validation runs locally in your browser.

Trust model: this tool can validate a path against the Root CA you supply. It cannot inspect the operating-system or browser trust store from a normal GitHub Pages application.

Planned checks

Private-key handling policy

          
    
            
  • Never uploaded or sent over the network.
    • 
            
  • Never written to localStorage, sessionStorage, IndexedDB or cookies.
    • 
            
  • Never included in diagnostic reports, logs or telemetry.
    • 
            
  • Held only in memory for the operation and cleared from application references afterwards.
    • 
            
  • No third-party analytics or CDN JavaScript.
