# Browser tests

Planned before stable `v0.1`:

- Chromium desktop/mobile viewport smoke tests.
- Firefox desktop smoke tests.
- WebKit desktop/mobile viewport smoke tests.
- Dynamic Intermediate CA add/remove/reorder flow.
- Four-level valid chain UI result.
- Wrong-order warning UI.
- Missing-intermediate UI.
- `fullchain.pem` copy/download interaction.
- Hostname valid/invalid states.
- CSP/no-network assertions.

Unit tests currently exercise the validation core without requiring a browser automation dependency.
